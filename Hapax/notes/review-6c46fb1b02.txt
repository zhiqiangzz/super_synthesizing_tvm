Verified algorithm:
1. Protect source reductions; repair only a demonstrated source-domain defect.
2. Fix B from the repaired source tuple and required outputs.
3. Try originals, then admissible complete rebase coefficient closure.
4. Preferred features: rebase coefficients and independently rebasable additive
   pieces, each with a defined B expression and retained structural expression.
   No arbitrary extraction of inner extrema; no special count injection.
5. Native cvc5 SyGuS searches preferred features, then preferred plus B. Each
   coordinate uses at most three feature occurrences under addition/subtraction.
   Nonlinear features count as single terminals. Width ordering is maximum first,
   then smaller widths. The two-copy specification requires information recovery.
6. Unknown semantic synthesis can fall back to native grammar enumeration.
   Every accepted proposal still needs independent executable recovery, domains,
   complete merge/leaf/output/printed-form verification. H is not jointly
   synthesized with C. Failed proof advances synthesis; failed accuracy does not.

State definitions for the fused registry operators
Source: data/fused_ops.json; expressions retain the recorded compiler notation.
Identifiers are local to each operator and chain. Source member definitions reproduce full-input formulas.
On a part S, interpret extent reads as specified in the paper: part-size reads become |S|,
while fixed program parameters retain their full-input values. For variance the denominator m becomes |S|;
the class count in label smoothing remains fixed. Derived reductions range over S.

  Chain 1, axis j
  Maintained state identifiers: row_max, den, O
  Source member definitions:

normalised policy loss [normalized_policy_loss]
  Chain 1, axis sample
  Maintained state identifiers: total, ss, loss_sum.h0, ss.r0, loss_sum.h0.r0
  Source member definitions:
    total[i0] = Σ_sample Advantage[i0, sample]
    mean[i0] = total[i0] / samples
    ss[i0] = Σ_sample Advantage[i0, sample]^2 + Σ_sample mean[i0]^2 - 2·Σ_sample Advantage[i0, sample]·mean[i0]
    scale[i0] = sqrt(ss[i0]) / (samples - 1)^1/2 + 1e-08
    loss_sum[i0] = Σ_sample Advantage[i0, sample]·LogProb[i0, sample] / scale[i0] - Σ_sample LogProb[i0, sample]·mean[i0] / scale[i0]
  Derived state definitions:
    loss_sum.h0 = Σ_sample Advantage[i0, sample]·LogProb[i0, sample] - Σ_sample LogProb[i0, sample]·mean[i0]
    ss.r0 = Σ_sample 1
    loss_sum.h0.r0 = Σ_sample LogProb[i0, sample]

  Derived state definitions:

    v22.r3 = 2·Σ_sample X[i0, sample, i2]·mean[i0, i1]·mean_view_i0_reduction_i2[i0, i2] + Σ_sample X[i0, sample, i1]·X[i0, sample, i2]^2 + Σ_sample X[i0, sample, i1]·mean_view_i0_reduction_i2[i0, i2]^2 - Σ_sample mean[i0, i1]·X[i0, sample, i2]^2 - 2·Σ_sample X[i0, sample, i1]·X[i0, sample, i2]·mean_view_i0_reduction_i2[i0, i2] - Σ_sample mean[i0, i1]·mean_view_i0_reduction_i2[i0, i2]^2
    v22.r4 = 2·Σ_sample X[i0, sample, i1]·mean[i0, i1]·mean_view_i0_reduction_i2[i0, i2] + Σ_sample X[i0, sample, i2]·X[i0, sample, i1]^2 + Σ_sample X[i0, sample, i2]·mean[i0, i1]^2 - Σ_sample mean_view_i0_reduction_i2[i0, i2]·X[i0, sample, i1]^2 - 2·Σ_sample X[i0, sample, i1]·X[i0, sample, i2]·mean[i0, i1] - Σ_sample mean_view_i0_reduction_i2[i0, i2]·mean[i0, i1]^2

\begin{abstract}
Many tensor operators use a value derived from one reduction's completed result as the context for another.
This dependency obstructs ordinary loop fusion, leaving experts to derive and implement single-pass algorithms.
Fusion requires retaining enough information for a join to correct partial results as contexts change without rereading input.
We present \sys, which adapts state synthesis and join construction from automated divide-and-conquer parallelisation to fuse dependent reductions.
Algebraic context separation establishes a sufficient condition for a single pass.
To retain source centring and scaling, \sys starts from the source reduction results and expresses their definitions using reference states that combine independently.
Synthesis searches only for auxiliary states that enable recovery of this representation; verified recovery then constructs a correct join over the reals.
Context-correction analysis supplies synthesis candidates and local-context evaluation formulas that retain the source's numerical structure where possible.
A recorded snapshot of our TVM implementation derives single-pass reducers for \nShowFused of \nShowcase selected operators; we report coverage, discovered states and derivation cost.
\end{abstract}

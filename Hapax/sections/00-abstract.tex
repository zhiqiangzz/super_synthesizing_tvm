\begin{abstract}
Many tensor operators use the completed result of one reduction as the context for another.
This dependency obstructs ordinary loop fusion, leaving experts to derive single-pass algorithms.
Fusion requires both a state representation and a join that corrects partial results when contexts change.
We present \sys, which adapts state synthesis from automated divide-and-conquer parallelisation to dependent reduction fusion.
Algebraic context separation constructs reference states with known joins and bounds the states sufficient for single-pass fusion, setting a default state-count limit for synthesis.
Reference-guided synthesis fixes source reduction results as initial states and searches only for auxiliary states that enable complete reference recovery.
Constructing and verifying recovery then determines the join, eliminating an independent join-synthesis task.
Context-correction coefficients further restrict this search by supplying candidate expressions with a role in updating the retained results.
The same corrections provide execution formulas that reuse source centring and scaling where possible, with the aim of retaining the source's numerical behaviour.
A recorded TVM snapshot derives single-pass reducers for \nShowFused of \nShowcase selected operators; we report coverage, discovered states and derivation cost.
\end{abstract}
